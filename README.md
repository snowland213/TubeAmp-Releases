# TubeAmp

**윈앰프 감성의 Windows 음악 플레이어 · 유튜브 MP3 변환기**

내 컴퓨터의 음악을 듣고, 10밴드 EQ로 소리를 조절하고, 앨범아트와 가사를 함께 보세요.
플레이어·재생목록·EQ 창을 원하는 자리에 놓거나, 앨범아트 중심의 미니 모드로 사용할 수 있습니다.
개인이 제작해 무료로 배포하는 프로그램입니다.

[설치·변경 사항](https://github.com/snowland213/TubeAmp-Releases/releases/tag/v3.1.1) · [문제 제보 / 기능 제안](https://github.com/snowland213/TubeAmp-Releases/issues)

## 어떤 기능이 있나요?

| 기능 | 할 수 있는 일 |
| --- | --- |
| 음악 재생 | MP3, WAV, OGG, FLAC, M4A 파일 재생 · 셔플 · 반복 재생 |
| 소리 조절 | 10밴드 EQ와 프리셋 · 음소거 · 0.5~2.0배 재생 속도 |
| 재생목록 | 파일·폴더 끌어놓기 · 순서 변경 · 검색 · 즐겨찾기 |
| 가사 | LRC 동기 가사 표시 · 온라인 가사 검색 |
| 화면 꾸미기 | 4가지 스킨 · UI 배율 조절 · 창 분리와 붙이기 · 앨범아트 미니 모드 |
| 유튜브 → MP3 | 주소를 넣어 변환 · 128 / 192 / 320 kbps 선택 · 저장 폴더 지정 |
| 온라인 업데이트 | 하루 한 번 새 버전 확인 · 앱에서 다운로드·검증·설치 |

## 처음 설치하기

1. [최신 릴리스](https://github.com/snowland213/TubeAmp-Releases/releases/latest)를 엽니다.
2. **Assets**에서 `TubeAmp-Setup-버전.exe`를 다운로드합니다. 현재 파일은 `TubeAmp-Setup-3.1.1.exe`입니다.
3. 설치 파일을 실행하고 안내에 따라 설치한 뒤 TubeAmp를 켭니다.
4. 음악 파일이나 폴더를 재생목록에 끌어다 놓고, 원하는 곡을 더블클릭합니다. `Ctrl + O`로 파일을 추가해도 됩니다.

음악 재생을 위해 Python이나 ffmpeg를 따로 설치할 필요는 없습니다. 필요한 구성요소가 설치 파일에 포함됩니다.
`.sha256`은 파일 검증용이며, GitHub가 표시하는 `Source code (zip / tar.gz)`는 실행·설치 파일이 아닙니다.

### 유튜브 MP3 변환을 쓰려면

인터넷 연결과 **[Node.js LTS](https://nodejs.org/)**가 필요합니다. Node.js 설치 후 TubeAmp를 다시 실행하세요.
`YT` 버튼으로 변환 창을 열고 **주소 붙여넣기 → 음질·저장 위치 선택 → MP3로 변환** 순서로 사용합니다.
온라인 가사 검색과 업데이트 확인에도 인터넷 연결이 필요합니다.

## 자주 쓰는 조작

| 키 / 조작 | 동작 |
| --- | --- |
| `Space` | 재생 / 일시정지 |
| `←` / `→` | 10초 뒤로 / 앞으로 |
| `Ctrl + ←` / `Ctrl + →` | 이전 곡 / 다음 곡 |
| `↑` / `↓`, 마우스 휠 | 음량 조절 |
| `M` | 음소거 |
| `Ctrl + O` | 음악 파일 추가 |
| `Ctrl + F` | 재생목록 검색 |
| `Ctrl + Z` | 재생목록에서 제거·비우기 되돌리기 |
| 앨범아트 클릭 / `Esc` | 미니 모드 열기 / 닫기 |
| `F1` / `F2` | 도움말 / 업데이트 확인 |

마우스 휠은 플레이어·EQ·미니 모드에서 음량만 5%씩 바꿉니다. 곡이나 재생 위치는 바뀌지 않습니다.
재생목록·가사·로그 위에서는 목록을 스크롤합니다. 더 많은 조작은 앱의 **?** 버튼 또는 `F1`에서 확인하세요.

## 업데이트

3.1.1부터 공식 배포 주소가 기본으로 연결되어 있습니다. 자동 확인을 켜 두면 하루 한 번 새 버전을 확인합니다.
직접 확인하려면 `F2`를 누르세요. 새 버전을 다운로드한 뒤 **설치하고 다시 실행**을 선택하면 됩니다.
변환 작업이 남아 있으면 작업을 마친 뒤 업데이트하세요.

- **3.0.2 이하:** 이번 설치 파일을 한 번 직접 설치해야 합니다.
- **3.1.0:** 업데이트 화면에 `snowland213/TubeAmp-Releases`를 한 번 등록하거나, 3.1.1 설치 파일로 업데이트하세요.

## 궁금한 점 / 문제 해결

**변환이 안 돼요.**  
Node.js 설치 여부를 확인하고 TubeAmp를 다시 켜세요. 계속 실패하면 `F2`로 최신 버전을 확인한 뒤 `LOG`에서 오류를 확인해 주세요. 유튜브 변경이나 영상별 제한에 따라 변환이 실패할 수 있습니다.

**가사가 없거나 곡과 맞지 않아요.**  
음악 파일과 같은 폴더에 같은 이름의 `.lrc` 파일을 넣거나, 가사 창의 온라인 검색을 사용하세요. 검색 결과와 동기 가사의 제공 여부는 곡마다 다릅니다.

**설치 파일에 ‘알 수 없는 게시자’가 표시돼요.**  
현재 배포본에는 코드 서명이 없습니다. 공식 릴리스의 파일 이름과 SHA256을 확인할 수 있습니다. Windows 보안 기능을 끄도록 권장하지 않습니다.

**설정은 어디에 저장되나요?**  
설정·재생목록·로그는 기본적으로 `%LOCALAPPDATA%\TubeAmp`에 저장됩니다. `F1 → 로그 폴더 열기`로 확인할 수 있습니다.

**어떻게 제거하나요?**  
Windows 설정의 **앱 → 설치된 앱 → TubeAmp → 제거**를 사용하세요.
